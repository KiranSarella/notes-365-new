#  Notebook Editor

# Overview
- if no notebook selected, display 'no notebook selected' message.
- if a notebook selected, then display markdown editor.
- save updated content in regular intervals of time (for every 10 sec)
- when notebook selected changed, update current notebook state and repeat same for new selection. 

# Inputs
notebook
notebooks path - base url

# Operations
load content from path to editor view
save content on regular intervals
close when notebook selected changed

# Outputs
saves updated content to respective path
